# 🧠 Algoritmos e Pensamento Computacional

Repositório destinado ao armazenamento e organização das **atividades, exercícios e desafios desenvolvidos durante as aulas de Algoritmos e Pensamento Computacional**.

Todos os exercícios deste repositório serão desenvolvidos utilizando a linguagem de programação **C**, com o objetivo de praticar lógica de programação, resolução de problemas e fundamentos da computação.

---

## 📚 Sobre o Repositório

Este repositório reúne as atividades propostas durante a disciplina, organizadas de forma a facilitar a consulta e acompanhar a evolução dos conhecimentos adquiridos.

### 📌 Conteúdos Trabalhados

* 🧩 Lógica de programação
* 📝 Algoritmos
* 📦 Variáveis e tipos de dados
* ⌨️ Entrada e saída de dados
* ➕ Operadores matemáticos e lógicos
* 🔀 Estruturas condicionais
* 🔁 Estruturas de repetição
* 📋 Vetores e matrizes
* 🔤 Strings
* ⚙️ Funções
* 📍 Ponteiros
* 🗂️ Estruturas de dados
* 📁 Manipulação de arquivos
* 💡 Resolução de problemas

## 💻 Linguagem Utilizada

### C

A linguagem **C** será utilizada para o desenvolvimento de todas as atividades e desafios deste repositório.

Os exercícios serão desenvolvidos utilizando conceitos fundamentais da linguagem, buscando melhorar progressivamente a lógica de programação e a capacidade de resolução de problemas.

## 🎯 Objetivos

* Desenvolver o pensamento computacional;
* Aprimorar a lógica de programação;
* Aprender os fundamentos da linguagem C;
* Praticar a criação e implementação de algoritmos;
* Desenvolver soluções para diferentes problemas;

* Registrar e acompanhar a evolução durante a disciplina.
