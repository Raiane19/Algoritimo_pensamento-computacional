# 🧮 Calculadora — 20 Operações

Projeto colaborativo desenvolvido como atividade prática da disciplina de **Algoritmos e Pensamento Computacional**.

O objetivo foi desenvolver uma calculadora capaz de executar **20 operações matemáticas e funções**, colocando em prática conceitos de lógica de programação, algoritmos e trabalho colaborativo utilizando Git e GitHub.

## 🎯 Objetivos

* Desenvolver uma calculadora com diferentes operações matemáticas;
* Praticar lógica de programação e construção de algoritmos;
* Trabalhar com estruturas e funções matemáticas;
* Utilizar o **Flowgorithm** para representação e execução dos algoritmos;
* Aprender a utilizar **Git e GitHub**;
* Praticar trabalho colaborativo;
* Dividir tarefas e integrar diferentes partes de um mesmo projeto.
